# M0 Definition of Done

M0 is done only when all of the following are true:

- the M0 technical shell exists and runs on representative iOS/Android devices
- the camera pipeline works with permission, lifecycle, and backpressure constraints
- the pose provider candidate is integrated and observable
- the canonical `PoseObservation` contract is stable
- normalization, metrics, phase, rep, fault, and feedback semantics are implemented for Squat only
- fixtures and replay produce deterministic outputs
- benchmark evidence is captured for viable runtime candidates
- privacy verification proves raw frames do not leave the device by default
- the M0 gate report is assembled and reviewable
- no additional AI-supported exercise has been started

## Non-goals that remain out of scope

- product MVP
- backend release
- website release
- AI Coach
- additional exercises
- M1/M2/V1 infrastructure
